# 💰 AI Smart Expense Tracker

AI Smart Expense Tracker is a full-stack web application developed using Python Flask and MySQL. The application helps users efficiently manage their daily expenses, track budgets, upload receipts, and monitor spending habits through an interactive dashboard.

The project includes advanced features such as expense analytics, PDF & Excel report generation, AI-based spending insights, profile management, dark/light theme support, and a dedicated Admin Dashboard for user management and system analytics.

## 🚀 Features

### User Features
- User Registration & Login
- Forgot Password Recovery
- Profile Management
- Add, Edit & Delete Expenses
- Receipt Upload & Management
- Budget Tracking
- Expense Search & Date Filters
- PDF Report Export
- Excel Report Export
- AI Spending Insights
- Dark / Light Theme

### Admin Features
- Admin Dashboard
- User Management
- User Analytics
- Total Expense Monitoring
- Role-Based Access Control

## 📊 Dashboard Analytics

- Total Expenses
- Total Transactions
- Budget Tracking
- Highest & Lowest Expense
- Average Expense
- Top Spending Categories
- Monthly Expense Trends
- Interactive Charts & Reports
